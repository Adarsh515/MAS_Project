## Project Overview

MAS_Project is an **AI Multi-Agent System (MAS) architecture** designed to facilitate the development, orchestration, and interaction of intelligent agents. The project provides a modular framework that enables developers to create, configure, and manage autonomous agents capable of collaborative problem solving, decision making, and task execution.

Key features include:
- **Modular agent design** with plug‑and‑play components.
- **Scalable communication** using message passing and shared knowledge bases.
- **Extensible tooling** for simulation, monitoring, and debugging.
- **Integration with popular AI libraries** (e.g., TensorFlow, PyTorch, LangChain).

## Usage Examples

Below are a few quick examples to get you started.

### 1. Running a simple MAS simulation
```python
from mas_project.core import MAS
from mas_project.agents import SimpleAgent

# Initialise the multi‑agent system
system = MAS()

# Add agents
system.add_agent(SimpleAgent(name="Agent A"))
system.add_agent(SimpleAgent(name="Agent B"))

# Run the simulation for 5 steps
system.run(steps=5)
```

### 2. Defining a custom agent
```python
from mas_project.agents import BaseAgent

class MyCustomAgent(BaseAgent):
    def perceive(self, environment):
        # Custom perception logic
        return environment.get_state()

    def decide(self, perception):
        # Simple decision rule
        return "action_based_on_" + perception

    def act(self, action, environment):
        environment.apply(action)
```

### 3. Using the CLI
The project ships with a command‑line interface for quick experiments.
```bash
python -m mas_project.cli --config examples/config.yaml --steps 10
```
